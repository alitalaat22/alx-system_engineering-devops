# 0x06 Regular Expressions Project

This project is part of the SE Foundations curriculum and focuses on building regular expressions using the **Oniguruma** library, the default regular expression library used by Ruby. The goal is to create efficient and flexible regex solutions for various scenarios.

## Project Overview

The purpose of this project is to practice creating regular expressions and applying them using Ruby scripts. Each task has a specific requirement that involves using regular expressions to match patterns or extract data.

## Concepts Covered

- Regular Expressions Basics
- Advanced Regular Expressions
- Usage of Ruby's **Oniguruma** library for regular expressions
