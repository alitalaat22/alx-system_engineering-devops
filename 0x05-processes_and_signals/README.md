# Project 0x05 - Processes and Signals

## Introduction
This project aims to understand and manage processes in a Linux environment using Bash. It includes a set of tasks covering how to find process IDs (PIDs), manage processes, and handle signals.

## Project Content
1. **0-what-is-my-pid**: A program that displays its own PID.
2. **1-list_your_processes**: Displays a list of all running processes.
3. **2-show_your_bash_pid**: Shows the PID of the current Bash process.
4. **3-show_your_bash_pid_made_easy**: Displays the PID and name of processes containing "bash".
5. **4-to_infinity_and_beyond**: Displays "To infinity and beyond" indefinitely.
6. **5-dont_stop_me_now**: Stops the 4-to_infinity_and_beyond process.
7. **6-stop_me_if_you_can**: Stops the 4-to_infinity_and_beyond process without using kill.
8. **7-highlander**: Displays "To infinity and beyond" and responds to SIGTERM signal.
9. **8-beheaded_process**: Kills the 7-highlander process.
10. **100-process_and_pid_file**: Manages PID in a file and responds to different signals.

## Project Requirements
- All files should end with a new line.
- Each Bash script must be executable.
- The first line in all Bash scripts should be: `#!/usr/bin/env bash`
- All scripts should include comments explaining their functionality.

## Learning Objectives
By the end of this project, you should be able to:
- Explain the concept of PID.
- Find the PID of a specific process.
- Manage processes and signals using Bash.
